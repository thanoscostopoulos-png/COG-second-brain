## How to Use These Reflections

### For Daily Review
1. Read the **frontend** reflection for that day (2 minutes)
2. Sit with the questions - don't rush to answer
3. If something doesn't land right, check **backend** for full reasoning
4. Note what works/doesn't in `reflection-framework.md`

### For Pattern Discovery
1. Read **backend** files sequentially to see pattern evolution
2. Look for repetitions across days (e.g., validation-seeking escalation)
3. Notice what gets emphasized vs. minimized

### For Framework Iteration
1. After reading all frontend reflections, update framework with examples of what worked/didn't
2. Regenerate reflections with updated framework to test changes
3. Archive old versions before creating new ones
